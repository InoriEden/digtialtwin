#  Digital Twin for Traffic Prediction

A digital twin system for traffic speed prediction and simulation based on time-series analysis and deep learning.

---

##  Overview

This project implements a digital twin framework for road traffic systems.
It integrates historical traffic data, graph structures, and deep learning models
to simulate and predict future traffic conditions.

Main features:
- Traffic speed data preprocessing and normalization
- Graph construction based on road correlations
- Custom PyTorch Dataset and DataLoader
- DCRNN/GRU-based prediction models
- Training and evaluation pipeline



##  Tech Stack

- Language: Python/UEC++/UEBluePrint
- Framework: torch
- Data Processing: NumPy, Pandas
- Visualization: Matplotlib
- Environment:  Windows

 ## Model Architecture
Historical Traffic Data (B×10×11)
            ↓
 Adaptive Graph Learning
 (Attention-based Q-K)
            ↓
 Spatially Aggregated Features
            ↓
     GRU (hidden=64)
            ↓
   Fully Connected Layer
            ↓
 Future Prediction (B×5×11)

 **##Dataset**

The dataset is derived from the paper:

**City-scale holographic traffic flow data based on vehicular trajectory resampling**
**link:https://www.nature.com/articles/s41597-022-01850-0**
The original dataset is generated by resampling real vehicle trajectories to construct large-scale urban traffic flow data.

In this project, we extract speed data of selected road segments, perform normalization and time-series segmentation, and use it for spatio-temporal prediction.
